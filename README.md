"Rift Koders: AI-Powered Coding Learning Platform" was developed. The platform aims to create an interactive environment where users can practice coding, improve problem-solving skills, and monitor their performance through various analytical and gamification features. The project combines the functionality of an online coding platform with intelligent evaluation mechanisms and user engagement tools, creating a comprehensive learning experience for programmers of different skill levels.

The primary purpose of Rift Koders is to provide users with a centralized platform for solving coding problems and evaluating their solutions automatically. The platform enables users to access coding challenges categorized by difficulty levels, write code using a professional coding editor, execute programs with custom inputs, and submit solutions for automated testing. The integrated AI Judge System evaluates submissions against predefined test cases and instantly provides feedback regarding correctness and performance. This immediate evaluation process helps users identify mistakes quickly and encourages continuous improvement.

In addition to code evaluation, the platform incorporates features designed to improve learning engagement and consistency. These features include an AI Hint System, Submission History, Daily Streak Tracking, Achievement Badges, Leaderboards, and Performance Dashboards. The AI Hint System assists users when they encounter difficulties while solving problems, while the streak and badge systems motivate users to practice coding regularly. The performance dashboard provides detailed insights into coding activity, helping users understand their strengths, weaknesses, and progress over time.

The development of this project also demonstrates the practical application of modern software engineering principles and web development technologies. The platform was developed using Python and Django for backend development, while HTML, CSS, Bootstrap, and JavaScript were used to create a responsive and user-friendly interface. The Monaco Editor was integrated to provide a professional coding environment similar to modern development tools, and SQLite was used for efficient data storage and management.

This project not only focuses on building a functional software application but also emphasizes the importance of user experience, learning efficiency, and technological innovation. Through the development of Rift Koders, practical knowledge gained from academic studies was successfully applied to create a real-world solution capable of addressing the challenges faced by coding learners and aspiring software developers.
